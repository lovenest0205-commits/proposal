# Do You Love Me? 💕

A cute, romantic "Do you love me?" webpage — built with **plain HTML, CSS, and JavaScript** (no frameworks, no libraries).

## How it works

- Click **Yes** → instant happy ending 😘
- Click **No** → the page guides you through a few playful, guilt-tripping pages trying to change your mind 🥺
- On the last page, the **No** button becomes impossible to click — it runs away to a random spot on screen every time you try to tap it!

## Features

- 🎨 Soft, romantic UI with elegant typography
- 💬 Custom GIFs and Hinglish captions on every page
- 🏃 Floating/dodging "No" button that never overlaps the "Yes" button
- 📱 Fully responsive — works on mobile and desktop
- ⚡ Zero dependencies — just open the HTML file in a browser

## Getting Started

Just open `love.html` in any browser — that's it!

> Prefer it split into separate files? `index.html`, `style.css`, and `script.js` are included too — keep them in the same folder and serve them together (e.g. via GitHub Pages, Netlify, or any local server).

## Customize it

Open the script and edit the `pages` array and `yesPage` object to swap in your own GIFs, names, and messages.
